**Goal:** Figma 로 만든 발표 슬라이드(PNG N장)를 부스 앱 안에서 넘기고, 지정한 슬라이드에서 "시연 시작" 버튼으로 기존 3라운드 투어를 돌린 뒤 다음 슬라이드로 돌아온다. 아이패드 한 대로 이사장님 발표를 끝낸다.

**Architecture:** 기존 `BoothStage` 상태머신(`apps/booth/lib/main.dart`)에 `presentation` 단계 하나를 추가한다. 슬라이드 목록·이동은 위젯을 모르는 순수 클래스 `SlideDeck`, 화면은 `PresentationScreen`. 진입은 어트랙트 화면 **오른쪽 위 5탭**(기존 왼쪽 위 5탭 리셋 제스처 클래스 `OperatorGesture` 재사용). 발표 중과 발표에서 시작한 투어 중에는 60초 무동작 리셋을 끈다.

**Tech Stack:** Flutter 3.38.6 / Dart 3.10, 외부 pub 패키지 **0개**(추가 금지), `flutter_test`. 기기: iPad Air 13" (M3), 가로 1366×1024 논리 픽셀.

**Spec:** 이 문서 §2(설계 결정)가 스펙이다. 별도 스펙 파일 없음.

## 1. 사람(현슈)이 하는 일 — 슬라이드 PNG 준비 (Opus 는 하지 않는다)

### 1-1. 비율 결정
아이패드 화면은 **4:3 (2732×2048 px)**. Figma 슬라이드가 16:9(1920×1080)면 위아래 검은 띠가 생긴다(앱은 검은 배경 + `BoxFit.contain` 이라 잘리진 않음). 가능하면 Figma 프레임을 **1366×1024** 로.

### 1-2. 방법 A — Figma 에서 직접 내보내기 (권장)
1. 슬라이드 프레임 이름을 `01`, `02`, … 로 바꾼다 (**한글·공백 금지** — iOS 빌드 에셋 경로 문제).
2. 프레임 전체 선택 → Export → `2x`, `PNG`.
3. 결과 `01.png` … `NN.png`.

### 1-3. 방법 B — PDF 에서 변환
```bash
brew install poppler                      # 한 번만
mkdir -p apps/booth/design
cp ~/Downloads/presentation.pdf apps/booth/design/presentation.pdf
cd apps/booth/design
pdftoppm -png -scale-to 2732 presentation.pdf slide     # slide-1.png … slide-N.png
for i in 1 2 3 4 5 6 7; do mv "slide-$i.png" "$(printf '%02d' $i).png"; done   # 장수에 맞게 숫자 조정
```
(macOS 기본 도구 `sips`/Preview 는 PDF 페이지별 PNG 를 못 뽑는다.)

### 1-4. 크기 조정 + 앱에 넣기
```bash
ls -la apps/booth/design/*.png            # 장당 3MB 초과면 아래 실행
sips -Z 2732 apps/booth/design/*.png      # 긴 변 2732 로 (이미 작으면 무변화)
mkdir -p apps/booth/assets/slides
mv apps/booth/design/0*.png apps/booth/assets/slides/
ls apps/booth/assets/slides               # 01.png 02.png …
```
PDF 원본은 커밋하지 않는다(Figma 가 원본). `apps/booth/design/` 은 `.gitignore` 에 추가한다(Task 4).

### 1-5. Opus 에게 넘길 값
1. 슬라이드 장수
2. **시연 슬라이드 번호**(1-base, 예: 4) → 코드 상수 `kDemoSlideIndex = 번호 - 1`
3. 비율(4:3 / 16:9)

시연 슬라이드는 **오른쪽 아래 320×110 px(1366 기준) 영역을 비워둔다** — 그 자리에 "시연 시작 →" 버튼이 겹친다.

### 1-6. 당일 하드웨어
USB-C → HDMI 어댑터로 미러링(별도 설정 없음). 설정 → 접근성 → **사용법 유도(Guided Access)** 켜기. 블루투스 프레젠터가 있으면 ←/→/PageUp/PageDown 로 넘길 수 있다.

import 'package:flutter/services.dart';

/// 발표 슬라이드 묶음 — 에셋 경로 목록과 현재 장. 위젯을 모른다.
///
/// 이사장님 발표(2026-09)용. 슬라이드는 Figma 에서 PNG 로 내보내
/// `assets/slides/01.png …` 에 둔 것뿐이고, 앱은 그걸 넘기기만 한다.
class SlideDeck {
  SlideDeck(this.paths, {this.demoIndex}) : assert(paths.isNotEmpty);

  /// 이름순. 첫 장이 `paths[0]`.
  final List<String> paths;

  /// "시연 시작" 버튼이 뜨는 장(0-base). null 이면 시연 없는 덱.
  final int? demoIndex;

  int index = 0;

  bool get isFirst => index == 0;
  bool get isLast => index == paths.length - 1;
  bool get isDemo => demoIndex != null && index == demoIndex;

  /// 다음 장. 마지막 장이면 false — 호출자가 "발표 끝"으로 처리한다.
  bool next() {
    if (isLast) return false;
    index++;
    return true;
  }

  /// 이전 장. 첫 장이면 false 로 무시.
  bool prev() {
    if (isFirst) return false;
    index--;
    return true;
  }

  /// 시연에서 돌아올 때 — 시연 장의 **다음** 장. 시연 장이 마지막이면 그 장.
  void returnFromDemo() {
    final d = demoIndex;
    if (d == null) return;
    index = (d + 1).clamp(0, paths.length - 1);
  }
}

/// 에셋 키 목록에서 `assets/slides/*.png` 만 이름순으로 골라 덱을 만든다.
/// 하나도 없으면 null — 슬라이드가 없는 부스 빌드에서는 발표 모드 자체가 없다.
///
/// 순수 함수로 떼어둔 이유: [AssetManifest] 는 테스트에서 가짜로 만들기 번거롭다.
/// 목록 → 덱 변환만 여기서 검증하고, 매니페스트 읽기는 한 줄짜리 [loadSlideDeck] 에 둔다.
SlideDeck? slideDeckFromAssetKeys(Iterable<String> keys, {int? demoIndex}) {
  final paths =
      keys
          .where((k) => k.startsWith('assets/slides/') && k.endsWith('.png'))
          .toList()
        ..sort();
  if (paths.isEmpty) return null;
  final demo = demoIndex != null && demoIndex >= 0 && demoIndex < paths.length
      ? demoIndex
      : null;
  return SlideDeck(paths, demoIndex: demo);
}

/// 앱 에셋 매니페스트에서 덱을 만든다. 슬라이드가 없으면 null.
Future<SlideDeck?> loadSlideDeck(AssetBundle bundle, {int? demoIndex}) async {
  final manifest = await AssetManifest.loadFromAssetBundle(bundle);
  return slideDeckFromAssetKeys(manifest.listAssets(), demoIndex: demoIndex);
}

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

import '../data/slide_deck.dart';

/// 발표 슬라이드 화면 (이사장님 발표, 2026-09).
///
/// 슬라이드 PNG 가 곧 화면이다 — 워드마크·여백·크로스페이드 어느 것도 얹지 않는다.
/// [BoothScaffold] 를 쓰지 않는 유일한 화면인 이유가 그것이다.
///
/// 입력은 세 갈래를 다 받는다: 화면 절반 탭(손), 스와이프(손), 키보드(블루투스
/// 프레젠터 리모컨은 PageDown/PageUp 또는 방향키를 보낸다).
class PresentationScreen extends StatefulWidget {
  const PresentationScreen({
    super.key,
    required this.deck,
    required this.onDemo,
    required this.onExit,
  });

  final SlideDeck deck;

  /// 시연 장의 "시연 시작 →".
  final VoidCallback onDemo;

  /// 마지막 장에서 한 번 더 넘겼을 때 — 발표 끝.
  final VoidCallback onExit;

  @override
  State<PresentationScreen> createState() => _PresentationScreenState();
}

class _PresentationScreenState extends State<PresentationScreen> {
  /// 스와이프로 인정하는 최소 속도. 이보다 느리면 "탭하려다 손이 밀린 것"으로 본다.
  static const double _swipeVelocity = 200;

  @override
  void initState() {
    super.initState();
    // 첫 넘김에서 흰 프레임이 번쩍이지 않도록 전 장을 미리 디코드해 둔다.
    // 실패(에셋 없음)는 무시 — 본문의 errorBuilder 가 받는다.
    WidgetsBinding.instance.addPostFrameCallback((_) {
      if (!mounted) return;
      for (final p in widget.deck.paths) {
        precacheImage(AssetImage(p), context, onError: (_, _) {});
      }
    });
  }

  void _next() {
    if (widget.deck.next()) {
      setState(() {});
    } else {
      widget.onExit();
    }
  }

  void _prev() {
    if (widget.deck.prev()) setState(() {});
  }

  KeyEventResult _onKey(FocusNode node, KeyEvent event) {
    if (event is! KeyDownEvent) return KeyEventResult.ignored;
    final k = event.logicalKey;
    if (k == LogicalKeyboardKey.arrowRight ||
        k == LogicalKeyboardKey.pageDown ||
        k == LogicalKeyboardKey.space) {
      _next();
      return KeyEventResult.handled;
    }
    if (k == LogicalKeyboardKey.arrowLeft || k == LogicalKeyboardKey.pageUp) {
      _prev();
      return KeyEventResult.handled;
    }
    return KeyEventResult.ignored;
  }

  @override
  Widget build(BuildContext context) {
    final deck = widget.deck;
    return Focus(
      autofocus: true,
      onKeyEvent: _onKey,
      child: GestureDetector(
        behavior: HitTestBehavior.opaque,
        onTapUp: (d) {
          final w = MediaQuery.sizeOf(context).width;
          d.localPosition.dx < w / 2 ? _prev() : _next();
        },
        onHorizontalDragEnd: (d) {
          final vx = d.velocity.pixelsPerSecond.dx;
          if (vx < -_swipeVelocity) _next();
          if (vx > _swipeVelocity) _prev();
        },
        child: ColoredBox(
          color: Colors.black,
          child: Stack(
            fit: StackFit.expand,
            children: [
              Image.asset(
                deck.paths[deck.index],
                fit: BoxFit.contain,
                filterQuality: FilterQuality.medium,
                // 다음 장이 디코드되는 사이 이전 장을 유지 — 검은 프레임 방지.
                gaplessPlayback: true,
                // 에셋이 없으면(테스트, 잘못된 파일명) 검은 화면 + 경로만.
                // 발표 중 빨간 에러 위젯이 뜨는 것보다 낫다.
                errorBuilder: (_, _, _) => Center(
                  child: Text(
                    deck.paths[deck.index],
                    style: const TextStyle(color: Colors.white24, fontSize: 14),
                  ),
                ),
              ),
              Positioned(
                right: 20,
                bottom: 16,
                child: Column(
                  crossAxisAlignment: CrossAxisAlignment.end,
                  mainAxisSize: MainAxisSize.min,
                  children: [
                    if (deck.isDemo) ...[
                      FilledButton(
                        onPressed: widget.onDemo,
                        style: FilledButton.styleFrom(
                          minimumSize: const Size(280, 76),
                        ),
                        child: const Text('시연 시작 →'),
                      ),
                      const SizedBox(height: 12),
                    ],
                    // 발표자용. 청중이 못 읽을 만큼만 흐리게.
                    Text(
                      '${deck.index + 1} / ${deck.paths.length}',
                      style: const TextStyle(
                        color: Colors.white38,
                        fontSize: 14,
                        fontFeatures: [FontFeature.tabularFigures()],
                      ),
                    ),
                  ],
                ),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
