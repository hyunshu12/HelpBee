# helpbee_booth

HelpBee 전시 부스 체험 앱 (2026-09-15 부스 행사용).

13인치 iPad, 가로 고정(1366×1024), 무인 운영, 지나가는 관람객이 서서 만지는 화면을
전제로 만들어졌다. 실제 AI 추론이나 네트워크 호출은 하지 않는다 — 사전에 계산해 둔
고정 결과(`assets/cases.json`)를 그대로 보여주는 오프라인 데모다.

- 설계 배경·화면 흐름·의사결정: `plans/2026-08-30_부스체험앱-설계.md`
- 현장 운영 절차(설치·점검·트러블슈팅): `docs/04-operation/booth-runbook.md`
